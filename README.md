# AI Profile Chat & Portfolio

A modern, interactive portfolio website built with **React**, **Vite**, and **Lucide Icons**, featuring smooth scroll animations, video background, and dark aesthetic design.

## ✨ Features

- ⚡ **Lightning Fast** - Built with Vite & React 19
- 🎨 **Modern Aesthetics** - Sleek dark mode design with glassmorphism and smooth responsive UI
- 🎥 **Interactive Video Canvas** - Scroll-linked video background animation
- 💼 **Portfolio Showcase** - Work experience, skills, education, and project highlights
- 📱 **Fully Responsive** - Optimized for mobile, tablet, and desktop viewports

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm / yarn / pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/IstiakPolok/polok_ai_profile.git
cd polok_ai_profile

# Install dependencies
npm install
```

### Running Locally

```bash
npm run dev
```

The application will be running at `http://localhost:5173/`.

### Building for Production

```bash
npm run build
```

The build artifacts will be generated in the `dist/` directory.

### Preview Production Build

```bash
npm run preview
```
